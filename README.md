# Be You Studio Hair — prévia de site

Landing page estática, one page e responsiva para a Be You Studio Hair, em Cascavel.

## Antes de apresentar como site oficial

- Trocar o wordmark tipográfico provisório pelo arquivo oficial da logo.
- Substituir as imagens ilustrativas do Unsplash por fotos autorizadas do salão e da equipe.
- Confirmar endereço, horário, serviços, telefone/WhatsApp e acesso ao perfil do Instagram com a empresa.
- Configurar domínio próprio e atualizar SEO/canonical/sitemap antes de solicitar indexação.

O projeto não inclui depoimentos inventados nem preços não confirmados.
